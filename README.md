# Warranty Vault

Warranty Vault is a web-based warranty management 
application designed to help users keep track of 
their products, warranty information, service 
history, documents, and warranty expiry dates.

## Features

- User registration and login
- User dashboard
- Product management
- Warranty and expiry tracking
- Product details
- Service history
- Document management
- Analytics
- User settings
- Admin dashboard
- Product and category management
- User management
- Reports

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Running the Project

This project is a static HTML, CSS and JavaScript 
application.

Clone the repository:

    git clone 
https://github.com/Ananya5105/Warranty-Vault.git
    cd Warranty-Vault

Open index.html in a web browser to run the 
application.
